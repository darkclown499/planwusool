# Books Store Theme

A warm, knowledge-oriented theme designed specifically for bookstores and book sellers.

## Design Features

### Color Palette
- **Primary**: Warm ambers (#f97316, #f59e0b)
- **Secondary**: Rich browns and golds (#92400e, #d97706)
- **Accent**: Soft yellows and creams (#fef3c7, #fffbeb)
- **Background**: Gradient from orange to yellow tones

### Typography
- **Headings**: Serif fonts for elegance and a classic reading feel
- **Body**: Sans-serif for readability
- **Emphasis**: Book-related decorative elements

### Visual Elements
- Book-themed decorative elements throughout the design
- Gradient backgrounds with warm tones
- Rounded corners and soft shadows
- Decorative dividers with book icons
- Wave patterns for visual interest

## Components

### Header
- Books-themed logo placeholder
- Warm color scheme with amber gradients
- Mobile-responsive navigation
- Search functionality with books-specific placeholder

### Hero Section
- Gradient background with scattered book-themed emojis
- Store information cards (location, hours, contact)
- Welcoming message with bookstore tagline
- Wave pattern at bottom for visual flow

### Category Tabs
- Book emoji icons for each category
- Horizontal scrolling on mobile
- Sticky navigation for easy access
- Smooth scrolling to category sections

### Product Grid
- Card-based layout with hover effects
- Star ratings for products
- Sale badges and out-of-stock overlays
- Warm color scheme for buttons and accents

### Footer
- Rich dark background with warm tones
- Comprehensive store information
- Opening hours and contact details
- Social media links
- Books-specific messaging

## Responsive Design

- **Mobile First**: Optimized for WhatsApp in-app browser
- **Tablet**: Improved grid layouts and spacing
- **Desktop**: Full-width layouts with enhanced visuals

## Unique Features

- Category-specific book emojis
- Books-themed messaging and copy
- Warm, inviting color palette
- Traditional bookstore aesthetic
- Book-focused visual elements

## Usage

This theme reuses all existing functionality from the base theme system while providing a completely unique visual experience tailored for bookstore businesses.
