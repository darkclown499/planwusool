# Flowers Store Theme

A modern, elegant e-commerce theme designed specifically for flowers and gifts stores.

## Features

- **Flowers-Focused Design** - Elegant layouts optimized for bouquets and floral gifts
- **Visual-First Approach** - Large product images, lookbooks, and style galleries
- **Complete E-commerce System** - Full shopping cart, checkout, and order management
- **Mobile-first Design** - Responsive layout optimized for all devices
- **Flowers-Specific Features** - Variant selection, delivery options, and more

## Components

- `FlowersStore` - Main theme component
- `Header` - Flowers-focused header with search, wishlist, cart
- `HeroSection` - Large banner with floral imagery
- `CategoryGrid` - Visual category navigation
- `ProductGrid` - Flowers product display with hover effects
- `Footer` - Elegant footer with brand information

## Styling

Flowers-focused color palette with elegant red accents.
