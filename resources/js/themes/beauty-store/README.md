# Beauty Store Theme

A modern, elegant e-commerce theme designed specifically for beauty and cosmetics stores.

## Features

- **Beauty-Focused Design** - Elegant layouts optimized for cosmetics and personal care
- **Visual-First Approach** - Large product images, lookbooks, and style galleries
- **Complete E-commerce System** - Full shopping cart, checkout, and order management
- **Mobile-first Design** - Responsive layout optimized for all devices
- **Beauty-Specific Features** - Variant selection, color recommendations, and more

## Components

- `BeautyStore` - Main theme component
- `Header` - Beauty-focused header with search, wishlist, cart
- `HeroSection` - Large banner with beauty imagery
- `CategoryGrid` - Visual category navigation
- `ProductGrid` - Beauty product display with hover effects
- `Footer` - Elegant footer with brand information

## Styling

Beauty-focused color palette with elegant fuchsia accents.
